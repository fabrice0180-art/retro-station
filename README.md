# Rétro Station — par Fabrice M.

Émulateur multi-consoles pour **Windows** et **Mac** (Intel et puce M) :
NES, Super Nintendo, Game Boy / Color / Advance, Nintendo 64, GameCube, Wii,
Master System, Mega Drive, Game Gear, Mega-CD, 32X, Saturn, Dreamcast,
Neo Geo, Neo Geo CD, Neo Geo Pocket / Color.

## Télécharger
Onglet **Releases** (à droite) :
- `RetroStation-Setup-…-Windows.exe` — PC
- `RetroStation-…-Mac-AppleSilicon.dmg` — Mac M1, M2, M3, M4…
- `RetroStation-…-Mac-Intel.dmg` — Mac Intel

## Fabriquer une nouvelle version
Onglet **Actions** > « Fabriquer les installateurs » > **Run workflow**.
Les trois installateurs apparaissent dans **Releases** au bout d'une quinzaine de minutes.

Mode d'emploi complet : `LISEZ-MOI.txt`.
L'émulateur ne fournit aucun jeu : importe les copies de tes propres cartouches et disques.
