RÉTRO STATION 1.0 — par Fabrice M.
=====================================

Émulateur multi-consoles pour PC (Windows 10/11) et Mac :
NES, Super Nintendo, Game Boy / Color / Advance, Nintendo 64, GameCube, Wii,
Master System, Mega Drive, Game Gear, Mega-CD, 32X, Saturn, Dreamcast,
Neo Geo, Neo Geo CD, Neo Geo Pocket / Color, PSP,
Atari 2600 / 5200 / 7800 / Lynx / Jaguar / ST, Amiga.


1. INSTALLATION
---------------
PC (Windows 10/11) : lance « RetroStation-Setup-…-Windows.exe ».
     Si Windows affiche « Windows a protégé votre ordinateur » :
     « Informations complémentaires » puis « Exécuter quand même ».
     Un raccourci « Rétro Station » est créé sur le bureau.

Mac (Intel ou puce M, un seul fichier pour tous) : ouvre « RetroStation-…-Mac-Universel.dmg »,
     puis glisse « Rétro Station » dans Applications.
     Au premier lancement, si le Mac refuse d'ouvrir l'appli :
     Réglages Système > Confidentialité et sécurité > « Ouvrir quand même ».

Au premier lancement, Rétro Station propose de télécharger ses moteurs
d'émulation (RetroArch, ses cœurs et Dolphin, environ 300 Mo, une seule fois).
Une connexion internet est nécessaire.


2. AJOUTER DES JEUX
-------------------
Bouton « + Importer des jeux » :
  - « Choisir des fichiers » : sélectionne tout d'un coup (Ctrl+A sur PC, Cmd+A sur Mac)
  - « Choisir un dossier entier » : tout le dossier et ses sous-dossiers
  - ou glisse tes fichiers directement sur la fenêtre.
Chaque jeu est reconnu et rangé tout seul dans sa console, et sa jaquette est
téléchargée automatiquement (si le fichier porte le nom officiel du jeu,
ex. « Super Mario World (Europe).sfc »). Si un fichier est ambigu
(certains .iso, .chd, .bin…), l'appli te demande une seule fois à quelle
console il appartient.

Un clic sur un jeu le lance. Clic droit : favori, jaquette perso, supprimer.
Chaque console est illustrée par une mini-photo, téléchargée au premier lancement.
Clic droit sur une console (à gauche) pour mettre ta propre photo.


2 bis. AFFICHAGE ET CONTOURS
---------------------------
Clic droit sur une console (à gauche) > « Affichage et contour d'écran »,
ou Paramètres > « Affichage des jeux » :
  - Contour : console portable, télé rétro, borne d'arcade, néon (au choix,
    avec la couleur et la taille de l'écran), ou aucun.
  - Taille de l'image : remplir l'écran, ou « pixels parfaits ».
  - Netteté (pixels nets / lissé) et effet d'écran (LCD, télé cathodique, lissage).
  - Plein écran ou fenêtre ; pour Wii / GameCube, la résolution 3D.
Par défaut, les consoles portables (Game Boy…) ont un contour et l'effet LCD.
Contour « Mon image de contour » : choisis un PNG (idéalement 1920 x 1080) dont la
zone de l'écran est transparente ; le jeu se cale tout seul dedans.
Clique sur « NINTENDO », « SEGA » ou « SNK » à gauche pour voir toute une famille.

2 ter. MÉNAGE : DOUBLONS ET ROMS DOUTEUSES
---------------------------------------
Bouton « Ménage » : Rétro Station repère les copies identiques, les différentes
versions d'un même jeu (France, Europe, USA, Japon, révisions) et les ROMs
douteuses (copies abîmées [b], prototypes, démos, fichiers vides, .zip cassés).
Les propositions sont cochées : tu choisis, puis « Mettre à la corbeille ».
Rien n'est effacé définitivement : tout passe par la corbeille de l'ordinateur.
Case « Une seule version de chaque jeu » : masque les doublons de régions sans
rien supprimer (la version française ou européenne est montrée en priorité).

3. BIOS
-------
Certaines consoles ont besoin du BIOS de ta propre console :
  - Neo Geo        : neogeo.zip (indispensable)
  - Mega-CD        : bios_CD_E.bin / bios_CD_U.bin / bios_CD_J.bin
  - Saturn         : mpr-17933.bin ou sega_101.bin
  - Neo Geo CD     : neocd_f.rom (ou neocd_z.rom…) + 000-lo.lo
  - Dreamcast      : dc_boot.bin + dc_flash.bin (recommandés)
  - Atari 5200     : 5200.rom (indispensable)
  - Atari Lynx     : lynxboot.img (indispensable)
  - Atari ST       : tos.img (indispensable)
  - Amiga          : kick34005.A500 (Kickstart 1.3) et kick40068.A1200 (3.1)
                     conseillés ; sans eux, un Kickstart libre intégré est utilisé
Amiga et Atari ST : la souris de l'ordinateur sert de souris de l'Amiga / du ST ;
  pour taper au clavier dans le jeu, appuie sur Arrêt défil (Scroll Lock).
Importe-les comme des jeux : ils sont rangés tout seuls au bon endroit.
Paramètres > « État des BIOS » montre ce qui manque.


4. COMMANDES
------------
Manette : reconnue automatiquement dans les jeux (PC et Mac).
Souris : un clic lance un jeu ; dans les jeux Wii, elle sert de pointeur.
Menu du jeu : F1 au clavier, ou Select + Start à la manette.
Régler les commandes EN PLEIN JEU : menu > Commandes > Port 1, puis choisis
  un bouton et appuie sur la touche voulue. C'est gardé automatiquement.
  (Clic droit sur une console > « Régler les commandes » rappelle la marche à suivre.)
Wii / GameCube : clic droit sur la console > « Régler les manettes » ouvre
  les réglages de manettes de Dolphin.
Clavier par défaut : flèches, X = A, Z = B, S = X, A = Y, Q/W = L/R,
  Entrée = Start, Maj droite = Select. F2 = sauvegarde rapide, F4 = chargement rapide.
Quitter un jeu : Échap, puis Échap une 2e fois pour confirmer
  (confirmation désactivable dans les Paramètres).
La partie reprend là où tu l'avais laissée.
Sur PC, la manette (type Xbox) permet aussi de naviguer dans les menus :
  A = jouer, B = retour, LB/RB = changer de console, Y = favori.


5. OÙ SONT MES FICHIERS ?
-------------------------
Dossier « RetroStation » dans ton dossier personnel
(C:\Users\<toi>\RetroStation sur PC, ~/RetroStation sur Mac) :
  Jeux/         tes jeux, un dossier par console
  BIOS/         les BIOS
  Sauvegardes/  parties, sauvegardes rapides, Wii/GameCube
  Jaquettes/    les images des jeux
  Moteurs/      RetroArch, cœurs, Dolphin
Il est volontairement en dehors de Documents pour ne pas remplir OneDrive / iCloud.


6. À SAVOIR
-----------
L'émulateur est légal ; les jeux que tu importes doivent provenir de tes
propres cartouches / disques. Rétro Station ne télécharge aucun jeu.
Moteurs utilisés (logiciels libres) : RetroArch (Mesen, Snes9x, Gambatte,
mGBA, Mupen64Plus-Next, Genesis Plus GX, PicoDrive, Beetle Saturn, Flycast,
FinalBurn Neo, NeoCD, Beetle NeoPop) et Dolphin.
Jaquettes : projet libre libretro-thumbnails.
Photos des consoles : Evan-Amos et contributeurs de Wikimedia Commons
(domaine public / CC BY-SA), téléchargées depuis commons.wikimedia.org.
Icône de l'appli et icônes de secours : créations originales.
